# 蓋普洛智慧物業管理系統

給社區管理委員會、物業管理中心使用的 Windows 程式：財務報表、零用金、採購比價、會議紀錄、公告、管理費催繳、行事曆、人事排班與打卡，都在同一套系統裡完成。

這個頁面提供 Windows 安裝檔下載。

---

## 下載安裝檔

### 方法一：直接點這裡下載（最簡單）

**[👉 按這裡下載最新版安裝檔](https://github.com/ArcQuantumLinkou/community-system-releases/releases/latest)**

點進去後，頁面最下方有一塊 **「Assets」**（附件），點裡面這個檔案就會開始下載：

**`Community-System_版本號_x64-setup.exe`**

例如：`Community-System_0.9.0_x64-setup.exe`

同一塊 Assets 裡的其他檔案都不用下載：

- `latest.json`：程式自動檢查更新用的。
- `Source code (zip)`、`Source code (tar.gz)`：GitHub 自動附上的，裡面沒有程式。

### 方法二：從這個頁面右邊找

1. 看這個頁面的**右邊欄**，「About」下面有一塊 **「Releases」**。
2. 點標著綠色 **「Latest」** 的那一版（例如 v0.9.0）。
3. 往下捲到 **「Assets」**，點 `.exe` 結尾的那個檔案下載。

用手機或視窗比較窄的時候，右邊欄會移到頁面最下面，請往下捲到底就會看到「Releases」。

---

## 安裝步驟

1. 打開剛下載的 `Community-System_…_x64-setup.exe`。
2. 如果跳出藍色視窗「**Windows 已保護您的電腦**」：
   先點視窗裡的「**其他資訊**」，再按「**仍要執行**」。
   這是因為程式還沒有購買微軟的程式碼簽章憑證，不是病毒。
3. 照畫面按「下一步」完成安裝。之後可以從「開始」功能表找到「蓋普洛智慧物業管理系統」。

不需要系統管理員權限，程式會安裝在目前登入的 Windows 帳號底下。

**從舊名稱更新過來的電腦**：系統原本叫「暖暖城智慧物業管理系統」，0.11.0 起改名為「蓋普洛智慧物業管理系統」。更新後開始功能表如果同時出現兩個名稱，可以到 Windows「設定 → 應用程式」把舊名稱那個解除安裝（不要勾選刪除資料），社區資料不受影響。

---

## 系統需求

- Windows 10 或 Windows 11（64 位元）。
- 第一次安裝時，如果電腦沒有 Microsoft WebView2（Windows 11 已內建），安裝程式會自動下載，請保持網路連線。

---

## 第一次使用

**建立管理員帳號**：第一次打開程式時，會請你設定管理員帳號和密碼。請記好密碼，畫面上提供的救援碼也請另外保存。

**試用與授權**：安裝後可以免費試用 30 天。要正式使用，請到「社區設定」分頁最上面的「軟體授權」，按「複製」把**這台電腦的機器碼**傳給我們，收到金鑰後貼回同一個地方，按「啟用金鑰」即可。

**從舊的網頁版搬資料過來**：在舊版的「資料備份」分頁，先按「匯出備份檔」（JSON），再按「匯出圖片備份」（zip）。到新程式的「資料備份」分頁，先匯入 JSON，再匯入 zip。

## 示範資料（先看看系統能做什麼）

我們準備了一份虛構的「暖暖城社區」示範資料，匯入後每個分頁都有內容可以看，適合第一次試用或向委員會展示。

**[👉 按這裡下載示範資料](https://github.com/ArcQuantumLinkou/community-system-releases/raw/main/%E7%AF%84%E4%BE%8B%E8%B3%87%E6%96%99/%E6%9A%96%E6%9A%96%E5%9F%8E%E7%A4%BE%E5%8D%80_%E7%A4%BA%E7%AF%84%E8%B3%87%E6%96%99.json)**

如果點了之後瀏覽器直接顯示一大段文字，沒有開始下載：在頁面上按右鍵 →「另存新檔」，存成 `暖暖城社區_示範資料.json`。也可以點這個頁面上方的 **「範例資料」** 資料夾 → 點檔案 → 按右上角的下載圖示（Download raw file）。

**匯入方式**：打開程式 →「資料備份」分頁 → 按「匯入備份檔」→ 選剛下載的 JSON。

⚠️ **匯入會整份覆蓋目前的資料**。請在還沒輸入自己社區的資料前匯入；如果已經有資料，系統會在匯入前自動下載一份現況備份，看完示範後可以再匯入那份備份還原。

示範資料內容：

- **財務報表**：2025 年 7 月到 2026 年 10 月共 16 個月，含經常性收支、頂樓防水工程、消防改善、轉存定存，另有一本充電樁帳本。
- **零用金**：每月明細與結存。
- **採購比價**：6 個案件，分別是已入帳、已決標、詢價中、取消等狀況；21 家虛構廠商。
- **會議紀錄**：管理委員會例會、臨時會、區分所有權人會議，含上次決議追蹤、附上試算表、下次會議時間。
- **規約**：社區規約、停車場管理辦法、交誼廳使用管理辦法，含修訂沿革。
- **簡報**：116 年度區權會簡報（委員候選人、財務摘要）。
- **人事排班**：2026 年 9～11 月，保全日夜輪班、清潔與行政班、特休、病假、代班、國定假日、人員離職與新進。
- **其他**：行事曆工作紀錄、公告、管理費催繳（存證信函、和解分期、已繳清）、試算表、特約店家。

示範資料裡的社區、人名、廠商、電話、統一編號都是虛構的。會議附圖與零用金單據照片不在示範資料內。

## 自動更新

有新版本時，打開程式會自動跳出更新詢問，按「立即更新」就會下載、安裝並重新開啟，**不需要再回到這個頁面下載**。

社區資料都存在這台電腦裡，更新程式不會影響資料。仍建議定期到「資料備份」分頁匯出備份。
